# Sage Field — Version 1.0.4

**Release Date:** May 2026

---

## Prospective Parent Flow

### Landing Screen Improvements

The landing screen now includes an "Interested in Sage Field?" text link (with a chevron icon) below the "Log in to continue" button, giving prospective parents a clear entry point without an account. The Privacy Policy · Terms of Use legal links have been moved to the very bottom of the screen.

---

### Prospective Parent Slideshow

Tapping "Interested in Sage Field?" opens a 7-slide full-screen informational modal for prospective families. The slides walk parents through the school's story, philosophy, teaching approach, class size, team, and family partnership model, ending with a CTA slide. Key details:

- Swipeable slides with a progress dot indicator (pill-style active dot), a Next button, and a Skip option that jumps directly to the CTA slide
- Team slide shows circular headshots for Ms. Sabrina (Lead Teacher, 2nd–4th), Ms. Paige (Lead Teacher, Pre-K–1st), and Ms. Zelinda (Teacher Aide) with name and role beneath each
- CTA slide offers three actions — Apply for a Program, Schedule a Free Tour, and Contact Us — each opening the corresponding page in the in-app browser
- Close button is correctly positioned below the Dynamic Island on all supported devices using explicit safe area insets

## Staff Updates

### Inventory Management

Staff can now manage a shared classroom inventory. From the More menu, tap Inventory to view and manage items. Each item has a title, category (Arts, Crafts, Science, Math, Writing, Sensory, Outdoor, General), status (Full / Running Out / Low), optional count, notes, and a classroom label. Items can have multiple photos — the primary photo appears on the card. Staff can log stock actions (taken / restocked) and submit shopping requests; requests track a full lifecycle (pending → approved / denied → purchased). Every item has an activity history showing all changes.

---

### Broadcast Messaging to Multiple Parents
Teachers can now send the same message to multiple parents in one action. Tapping "New Message" opens a two-step compose flow: the first step shows a structured parent directory — your students' parents appear at the top, followed by all other parents — with a search bar that filters by parent name or child name. Select as many recipients as needed, and selected parents appear as removable chips. The second step is a compose screen with a "To:" summary, a message input, optional image attachment, and a Send button that labels itself "Send to N" when multiple recipients are selected. Tapping Send creates or finds an individual conversation with each recipient and broadcasts the message to all of them at once.

---

### Post Reactions

Staff and parents can now react to feed posts with emoji. Reaction pills (emoji + count) appear at the bottom of each post card. Tap a pill to toggle your own reaction on or off; tap the "+" button to open a full emoji picker and react with any emoji. A brief animated particle effect plays when you add a reaction. Long-press any reaction pill to open a sheet showing who reacted — the sheet has emoji tabs at the top (each labeled with its emoji and count) and a scrollable list of avatars and names for the selected emoji.

## Bug Fixes

### Inventory Grid Layout with Odd Item Count

Fixed a visual misalignment in the inventory 2-column grid when the filtered list contained an odd number of items. A null placeholder is now appended when the count is odd, rendering as an invisible spacer that keeps both columns balanced.

---

### Inventory Photo Upload on Device

Fixed inventory photo uploads failing on device. React Native's runtime does not support `blob.arrayBuffer()`, so the Supabase SDK `upload()` call was replaced with a direct HTTP `POST` to the Supabase Storage REST API, passing the blob as the request body with `x-upsert: true` and a `Bearer` token from the current session.

---

## Improvements

### Error Visibility Across Parent and Staff Screens

All important parent and staff screens now send error notifications to Discord when async operations fail. Previously most failures were either shown only to the user as a local error message or silently swallowed — the team had no production visibility. The Stripe checkout flow additionally captures errors in Sentry. Every notification automatically includes the affected user's ID and email.

---

### Message Channel Join Error Handling

Both the staff and parent message channel screens now show an alert if the channel-join RPC returns null, with options to dismiss or navigate to Help. Previously this failure was silent.
